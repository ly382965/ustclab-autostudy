# ustclab-autostudy

中国科学技术大学实验室安全准入考试（`sysaq.ustc.edu.cn`）全自动学习与挂机助手。

支持 USTC 统一身份认证（CAS）、断点续刷、心跳保活、规避 5 分钟无操作登出，支持全后台无感刷课。

---

## 特性

- **统一身份认证与安全凭据管理**：基于 USTC CAS 认证，支持环境变量及外部本地配置文件，自动获取并持久化长效 Session，避免明文泄露。
- **精确逆向通信协议**：完整逆向 `lab-study-front` 前端的 MD5 动态签名机制与请求接口，模拟真实客户端。
- **15秒定时心跳挂机**：严格遵循官方 15 秒心跳协议，彻底解决官方前端 5 分钟弹窗强退及单篇学完不自动切课的问题。
- **断点续刷与状态总览**：自动拉取全部 58 门课程（40 门必修 + 18 门选修）的进度，优先完成必修，随时 `Ctrl+C` 中断，无缝续刷。

## 快速开始

### 1. 环境准备

确保本机已安装 Python 3.10+，并安装依赖：

```bash
pip install -r requirements.txt
```

> **注意**：脚本首次登录时会通过本地已安装的 Microsoft Edge 浏览器无头模式置换 Session Token，无需额外安装繁重的浏览器内核。

### 2. 配置账号凭据

为了账号安全，**强烈建议使用环境变量**提供凭据，避免在代码中硬编码。

#### 推荐方式：环境变量

- **Windows PowerShell**:
  ```powershell
  $env:USTC_CAS_USR = "SAxxxxxxx"
  $env:USTC_CAS_PWD = "你的统一身份认证密码"
  ```
- **Windows Command Prompt (cmd)**:
  ```cmd
  set USTC_CAS_USR=SAxxxxxxx
  set USTC_CAS_PWD=你的统一身份认证密码
  ```
- **Linux / macOS**:
  ```bash
  export USTC_CAS_USR=SAxxxxxxx
  export USTC_CAS_PWD=你的统一身份认证密码
  ```

#### 备用方式：本地配置文件

复制 `config.example.json` 为 `config.json`（该文件已被 `.gitignore` 排除，不会上传）：

```bash
cp config.example.json config.json
```

编辑 `config.json`：
```json
{
  "username": "SAxxxxxxx",
  "password": "你的统一身份认证密码",
  "exam_id": 45,
  "mode": "must"
}
```

## 使用方法

### 1. 查看当前学习进度总览（不执行刷课）

```bash
python study_bot.py --status
```

控制台将输出格式化的进度面板：
```text
============================================================
【实验室安全准入考试 (Task 45) 学习进度总览】
必修课程: 0/40 篇已完成 | 时长: 00:01:29 / 03:56:00 (0.6%)
选修课程: 0/18 篇已完成 | 时长: 00:00:00 / 00:35:00 (0.0%)
总计剩余需学习: 必修 03:54:31 | 选修 00:35:00
============================================================
```

### 2. 开始挂机刷课（默认优先刷必修课）

直接运行主脚本（Windows 用户也可双击 `run.bat`）：
```bash
python study_bot.py
```

### 3. 刷全部课程（必修 + 选修）

```bash
python study_bot.py --mode all
```

### 4. 命令行参数

| 参数 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `--status` | 否 | 仅查看当前进度总览，不执行刷课 |
| `--mode` | `must` | `must` (仅必修), `all` (必修+选修), `opt` (仅选修) |
| `--exam-id` | `45` | 考试任务 ID（默认为 2026 级新生考试 45） |
| `--usr` | 环境变量 / 配置 | 统一身份认证学号 |
| `--pwd` | 环境变量 / 配置 | 统一身份认证密码 |

## 常见问题

1. **学习时长没有立即在网页端显示？**
   - 官方平台采用异步结算机制，每次学习心跳上传后，前端界面展示的总时长会在 5 分钟左右汇总更新，属正常现象。
2. **中途可以关闭或断网吗？**
   - 可以随时按 `Ctrl+C` 中断程序。已上传的心跳在服务器端实时保存，下次启动会自动跳过已达标课程并断点续学。
